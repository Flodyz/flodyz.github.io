# flodyz.github.io

Página de projetos de João Gabriel, desenvolvedor full stack: https://flodyz.github.io/

- `/`: apresentação, projetos e como trabalho.
- `/projetos/<projeto>/`: estudo de caso de cada projeto.
- `/demo/facgestor/` e `/demo/nero/`: builds estáticos das demos, com dados fictícios e sem backend.

Este repositório guarda só o HTML gerado. As páginas são produzidas por um script Node a partir de estudos de caso em Markdown; o código-fonte das demos não é publicado.
